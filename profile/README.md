## InfraCraft Labs

Tested DevOps fixes, guides and reference code for software teams without a platform team.

Everything here is a **reference implementation** or **technical demonstration**: small,
documented and runnable on a laptop or a free tier. None of it is client work.

- **Site:** [infracraftlabs.com](https://infracraftlabs.com), with short, tested posts on CI/CD, Kubernetes, Infrastructure as Code, cloud and security
- **Principles:** standard tools, secure defaults (short-lived credentials, least privilege, pinned versions), and a README that gets you running in minutes
- **Licence:** code is MIT-licensed unless a repository says otherwise
- **Security:** please report issues privately, see [SECURITY.md](https://github.com/infracraftlabs/.github/blob/main/SECURITY.md)

Questions about a repository? Open an issue, or write via [infracraftlabs.com/contact](https://infracraftlabs.com/contact/).
