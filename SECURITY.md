# Security policy

This policy applies to every repository in the `infracraftlabs` organisation.

## Reporting a vulnerability

Please **don't** open a public issue for security problems.

- Use GitHub's **Report a vulnerability** button on the repository's *Security* tab (private
  vulnerability reporting), or email hello@infracraftlabs.com with the subject "Security report".
- Include what you found, where, and how to reproduce it.
- You'll get a reply within three working days, and updates until it is fixed.

## Scope

The code here is reference and demonstration material. It uses placeholder values and
contains no real hosts, keys or account IDs. If you find something that looks like a real
secret, please report it as above.

There is no bug bounty, but I'm glad to credit reporters once a fix is out.
